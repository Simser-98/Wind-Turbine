## Data Exploration & EDA

Wind turbine SCADA data analysis including exploratory data analysis 
and feature engineering.

### Dataset
Download the dataset from [Kaggle](https://www.kaggle.com/datasets/berkerisen/wind-turbine-scada-dataset) and place the CSV in the `data/` folder.

### Files
- `wind_analysis.ipynb` — Jupyter notebook with full EDA and visualizations

### Requirements
pip install pandas numpy matplotlib
